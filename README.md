# CyberQuest — «Кібердетектив»

Одиночна гра з кібербезпеки для дітей 9–14 років (ITSTEP Academy Житомир). Є портативна версія для Windows у режимі кіоску та вебверсія для телефонів з тим самим сюжетом.

## Як грати
- Агент ходить містом: **WASD / стрілки** або **клік мишкою** (персонаж сам знаходить шлях).
- Підійти до персонажа з жовтим **«!»** і натиснути **E** (або клікнути по ньому) — він дає завдання.
- Завдання (міні-ігри): 🔎 сканування екрана інструментами (клавіші 1–4), 💬 чат-бій із шахраєм на таймер, ⚡ аркада «безпечно / небезпечно» (← →), 🔐 протокол (кроки по порядку), 🎬 кат-сцени.
- Енергія **ЩИТа** падає за помилки. Якщо 0 — місія перезапускається.
- У штабі — **стіл планування** з дошкою справи (зачіпки й ключі на сітці).
- Після 6 ключів відкриваються ворота серверної — фінальна битва з «Соня_2014».
- На телефоні торкайся мапи, щоб іти, або персонажа, щоб поговорити. Інструменти сканування, відповіді в чаті, варіанти в аркаді та кроки протоколу можна вибрати на екрані.

## Хронометраж (~30 хв, діти 9–14)
| Відрізок | Ціль |
|---|---|
| Вступ, штаб, Командир | 2:00 |
| М1 Фішинг (2 скани + аркада) | 4:30 |
| М2 Профілі (2 скани + чат) | 4:30 |
| М3 Код із СМС (чат, кат-сцена, протокол) | 3:30 |
| М4 Ігрові паролі (скан, чат, протокол) | 4:00 |
| М5 Фото й дані (чат + аркада) | 3:30 |
| М6 AI-фото й шантаж (фейк-фото, справжнє фото, чат, протокол) | 5:00 |
| Фінал + сертифікат | 3:00 |
| **Разом** | **30:00** |

- Таймери під вік: 25 с на відповідь у чаті (бос — 18 с), 9 с на картку в аркаді (фінал — 7 с), 2:30 на скан, 1:15 на протокол.
- **Адаптивна допомога:** після 2 помилок у сцені гра підсвічує потрібний інструмент / правильну відповідь / наступний крок. Якщо місія триває довше за свою ціль або вся гра довше 30 хв — Командир вмикає підказки одразу. Так повільні гравці теж укладаються, а швидкі проходять за ~20 хв.
- У шапці — час гри `хв / 30:00` (жовтіє після 30 хв).
- Усе налаштовується в `src/content/pack.js` → `timing`.

## Запуск на Windows
- Кіоск (як на івенті): `npm start`
- Розробка у вікні: `npm run dev` — тут працюють чіти **F9** (зарахувати місію) і **F8** (пропустити сцену)
- Збірка: `npm run dist` → `dist/CyberQuest.exe`

## Запуск на телефонах через локальну мережу

1. Запустіть `node tools/serve.js --lan` (або `npm run web -- --lan`) на ПК з Node.js. Залежності Electron для вебверсії не потрібні.
2. Під’єднайте телефони до тієї самої мережі Wi-Fi та відкрийте на них адресу локальної мережі, яку виведе команда, наприклад `http://192.168.1.10:5173/`. Якщо Windows запитає про доступ до мережі, дозвольте його для приватної мережі.
3. Натисніть «Почати розслідування». ПК має залишатися увімкненим, а сервер має працювати, поки діти грають через звичайний HTTP. Для перевірки на самому ПК можна запустити `npm run web` і відкрити `http://localhost:5173/`.

### Установлення та гра офлайн

Для першого відкриття встановлюваного застосунку телефон має отримати сторінку через **HTTPS із сертифікатом, якому він довіряє**. Публічний хостинг необов’язковий. Якщо у вас є такий сертифікат для адреси або імені ПК у локальній мережі, запустіть `node tools/serve.js --lan --cert cert.pem --key key.pem`, підставивши шляхи до своїх файлів, і відкрийте відповідну HTTPS-адресу з портом `5173`. Вебверсію також можна розмістити як звичайний статичний сайт, використовуючи вміст папки `src/`.

- **Android (Chrome)** — натисніть «Встановити гру» або скористайтеся меню браузера.
- **iPhone (Safari)** — натисніть «Поділитися» → «На початковий екран». Увімкніть «Відкрити як вебпрограму», якщо є такий перемикач.
- Відкрийте CyberQuest з іконки, поки телефон ще має зв’язок із ПК або сайтом. Дочекайтеся повідомлення «Готово до гри офлайн». Після цього гру можна знову відкривати з іконки без зв’язку. Прогрес розслідування зберігається лише до закриття або перезавантаження гри.

Після оновлення файлів вебверсії збільшуйте версію кешу в `src/sw.js`, щоб установлені копії отримали зміни після наступного підключення.

## Для організатора
- **Вихід:** 5 швидких кліків по логотипу ITSTEP (вгорі зліва) → «Вийти».
- 🙋 у шапці — пауза й виклик ментора; 🔊 — звук.
- Музика: `src/audio/music.mp3` (взята з наданого відео). Звукові ефекти синтезуються в коді.
- Контент для інших філій: покладіть `pack.js` поруч з exe (формат — `src/content/pack.js`).
- Ctrl+Alt+Del і клавішу Win програмно не заблокувати — для повного кіоску потрібні політики Windows (Assigned Access).

## Структура
- `main.js` — вікно кіоску
- `src/world.js` — 2D-місто, ходьба, пошук шляху, NPC, мінікарта
- `src/game.js` — HUD, діалоги, міні-ігри, стіл планування, сертифікат
- `src/sfx.js` — звук
- `src/content/pack.js` — сюжет і всі тексти
