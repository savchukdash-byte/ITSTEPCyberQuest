# CyberQuest — «Кібердетектив»

Одиночна гра з кібербезпеки для дітей 9–14 років (ITSTEP Academy Житомир). Один portable-exe, повний екран (кіоск).

## Як грати
- Агент ходить містом: **WASD / стрілки** або **клік мишкою** (персонаж сам знаходить шлях).
- Підійти до персонажа з жовтим **«!»** і натиснути **E** (або клікнути по ньому) — він дає завдання.
- Завдання (міні-ігри): 🔎 сканування екрана інструментами (клавіші 1–4), 💬 чат-бій із шахраєм на таймер, ⚡ аркада «безпечно / небезпечно» (← →), 🔐 протокол (кроки по порядку), 🎬 кат-сцени.
- Енергія **ЩИТа** падає за помилки. Якщо 0 — місія перезапускається.
- У штабі — **стіл планування** з дошкою справи (зачіпки й ключі на сітці).
- Після 6 ключів відкриваються ворота серверної — фінальна битва з «Соня_2014».

## Хронометраж (~30 хв, діти 9–14)
| Відрізок | Ціль |
|---|---|
| Вступ, штаб, Командир | 2:00 |
| М1 Фішинг (2 скани + аркада) | 4:30 |
| М2 Профілі (2 скани + чат) | 4:30 |
| М3 Код із СМС (чат, кат-сцена, протокол) | 3:30 |
| М4 Ігрові паролі (скан, чат, протокол) | 4:00 |
| М5 Фото й дані (чат + аркада) | 3:30 |
| М6 AI-фото й шантаж (фейк-фото, справжнє фото, чат, протокол) | 5:00 |
| Фінал + сертифікат | 3:00 |
| **Разом** | **30:00** |

- Таймери під вік: 25 с на відповідь у чаті (бос — 18 с), 9 с на картку в аркаді (фінал — 7 с), 2:30 на скан, 1:15 на протокол.
- **Адаптивна допомога:** після 2 помилок у сцені гра підсвічує потрібний інструмент / правильну відповідь / наступний крок. Якщо місія триває довше за свою ціль або вся гра довше 30 хв — Командир вмикає підказки одразу. Так повільні гравці теж укладаються, а швидкі проходять за ~20 хв.
- У шапці — час гри `хв / 30:00` (жовтіє після 30 хв).
- Усе налаштовується в `src/content/pack.js` → `timing`.

## Запуск
- Кіоск (як на івенті): `npm start`
- Розробка у вікні: `npm run dev` — тут працюють чіти **F9** (зарахувати місію) і **F8** (пропустити сцену)
- Збірка: `npm run dist` → `dist/CyberQuest.exe`

## Для організатора
- **Вихід:** 5 швидких кліків по логотипу ITSTEP (вгорі зліва) → «Вийти».
- 🙋 у шапці — пауза й виклик ментора; 🔊 — звук.
- Музика: `src/audio/music.mp3` (взята з наданого відео). Звукові ефекти синтезуються в коді.
- Контент для інших філій: покладіть `pack.js` поруч з exe (формат — `src/content/pack.js`).
- Ctrl+Alt+Del і клавішу Win програмно не заблокувати — для повного кіоску потрібні політики Windows (Assigned Access).

## Структура
- `main.js` — вікно кіоску
- `src/world.js` — 2D-місто, ходьба, пошук шляху, NPC, мінікарта
- `src/game.js` — HUD, діалоги, міні-ігри, стіл планування, сертифікат
- `src/sfx.js` — звук
- `src/content/pack.js` — сюжет і всі тексти
